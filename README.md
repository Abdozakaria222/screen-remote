# ريموت الشاشات (Screen Remote)

تطبيق أندرويد يبحث عن الشاشات الذكية على نفس شبكة الواي فاي، يعرضها في قائمة،
وبعد اختيار شاشة يتحوّل الهاتف إلى ريموت للتحكم بها (تنقّل، موافق، رجوع، صوت، تشغيل…).

## الأنواع المدعومة

| النوع | البروتوكول | الاقتران | درجة الثقة |
|------|-----------|---------|-----------|
| **Roku / UPnP** | HTTP ECP (منفذ 8060) | لا يحتاج | عالية جداً |
| **سامسونج (Tizen)** | WebSocket (منفذ 8002) | قبول على الشاشة أول مرة + توكِن يُخزَّن | عالية |
| **LG (webOS)** | WebSocket (منفذ 3000) + سوكِت مؤشر | قبول على الشاشة أول مرة + مفتاح يُخزَّن | جيدة |
| **Android TV / Google TV** | Remote v2 (TLS، منفذا 6466/6467، protobuf) | كود سداسي يظهر على الشاشة | تجريبية — تحتاج اختبار على جهاز |

> **ملاحظة مهمة:** لا يوجد بروتوكول واحد يتحكم في كل الشاشات. البحث عن الأجهزة موحّد
> (SSDP + مسح المنافذ على الشبكة)، لكن التحكم مُقسَّم إلى وحدة لكل ماركة. وحدة Android TV
> هي الأعقد (تشفير TLS + حساب سر الاقتران) وقد تحتاج ضبطاً بسيطاً بعد التجربة على جهازك.

## كيفية البناء عبر GitHub Actions

1. أنشئ مستودعاً جديداً على GitHub وارفع عليه محتويات هذا المجلد كما هي.
2. ادخل تبويب **Actions** — سيبدأ سير العمل "Build APK" تلقائياً مع كل رفع.
3. بعد نجاح البناء، افتح التشغيل الأخير ونزّل ملف **screen-remote-debug-apk** من قسم Artifacts.
4. فكّ الضغط وثبّت `app-debug.apk` على الهاتف (فعّل "تثبيت من مصادر غير معروفة").

يمكنك أيضاً تشغيل البناء يدوياً من زر **Run workflow**.

## البناء محلياً (اختياري)

يحتاج JDK 17 و Android SDK (platform 34):

```bash
gradle assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

لو عندك Android Studio، افتح المجلد مباشرة ونفّذ Build > Build APK.
(ملف الـ wrapper jar غير مرفق لتقليل الحجم؛ لتوليده محلياً: `gradle wrapper`.)

## طريقة الاستخدام

1. تأكد أن الهاتف والشاشة على **نفس شبكة الواي فاي**.
2. افتح التطبيق واضغط **بحث عن الشاشات** (يبدأ البحث تلقائياً).
3. اختر الشاشة من القائمة.
4. حسب النوع:
   - **Roku:** يتصل فوراً.
   - **سامسونج / LG:** ستظهر نافذة "السماح" على التلفزيون — اقبلها. بعدها لن تتكرر.
   - **Android TV:** سيظهر كود سداسي على التلفزيون — أدخله في التطبيق.
5. استخدم الأزرار كريموت عادي.

## استكشاف الأخطاء

- **لا تظهر أي شاشة:** تأكد من نفس الشبكة؛ بعض الراوترات تمنع البث متعدد الوجهات
  (AP Isolation) — عطّله من إعدادات الراوتر.
- **سامسونج لا يتصل:** الموديلات الأقدم من 2016 قد تستخدم المنفذ 8001 بدون تشفير
  (غير مدعوم في هذا الإصدار بعد).
- **Android TV يفشل في الاقتران:** راجع سجلّ الأخطاء؛ خطوة حساب السر أو ترتيب رسائل
  الاقتران قد تحتاج ضبطاً حسب موديل الجهاز.
